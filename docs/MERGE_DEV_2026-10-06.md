## What arrived

- **Plugin short names are gone** (`f69a9193ab`). `PluginDescription.shortName`,
  `PluginBase.shortName` and every English `*_shortname` / `*_short` string that only
  fed the old tab bar were removed. Omnipod plugins are now "Omnipod Eros" and
  "Omnipod Dash".
- **Loop pause safety (#5192 / `3f61875482`)**: while the running mode pauses the loop,
  an open-loop suggestion is dismissed instead of left on the phone and the watch where
  it could still be accepted.
- **Unknown running mode shows as unknown** (`02877a5524`), not as "loop disabled".
  `getRunningModeActiveAtOrNull` can return null on purpose.
- **Keep the cached IOB when a new BG arrives** (`2e4d7be3c7`): `bgDataReloaded()` drops
  old entries instead of `clearCache()`.
- **Wear resend is debounced, not sampled** (`3b9b3786d9` and friends): one
  `resendRequests` channel with `debounce(2.seconds)` replaces per-event `sample()`
  throttles, so a burst of events costs one resend and no event is lost at start.
- **Persistent notification / Samsung Live Update**: `POST_PROMOTED_NOTIFICATIONS`,
  Samsung `ongoing_activity` meta-data, one update per burst of events, delta in the
  Now Bar primary line.
- **Client control**: a preference slider saves only when the finger is lifted.
- **Range lookups load every entry running at the start of the range**
  (`09ea9653d9`) — one batch read, not a query per sample.
- **Time zone change recalculates IOB from scratch** (`0c1a56ee79`).
- **Automation: an unknown trigger never fires** (`37fdc869f6`).
- **Command queue: a dropped bolus does not save its carbs** (`e4a833f782`).
- **Equil is a patch pump** (200 U reservoir).
- **Omnipod drift compensation is always on** (`df4167e111`) — the engineering
  semaphore file is gone, and with it `ExternalOptions.ENABLE_OMNIPOD_DRIFT_COMPENSATION`.
- Dependabot: guava 33.7.2-jre, commons-lang3 3.21.0, joda-time 2.15.0. Plus Crowdin.
- iOS work on the upstream side (setup wizard on first run, keep screen on, Keychain
  queries as real CFDictionaries) does not change the Android gates here.
