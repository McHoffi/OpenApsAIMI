## What arrived from upstream

- **Overview graphs follow scroll and zoom on every frame.** The graphs below BG share the
  window with the BG chart, without time labels and closer together. Zoom is applied once
  (not every frame) and scroll corrects Vico's own centring before the next frame, so a pinch
  no longer drifts sideways (#5293 follow-up).
- **Glucose graph details popup.** Press and hold the BG graph to read the values at a point.
  `GraphInspectState`, an inspect line on every graph, and a spoken prediction summary that
  names the biggest excursion of each curve (up / down / flat).
- **Future IOB and activity reach the prediction horizon again** on the graphs.
- **Bolus Wizard.** The secondary numbers collapse into one row that can be nudged or opened.
  A dose above the max bolus is capped with a warning again, not refused. No delivery-failed
  alarm when the user stopped a bolus the driver reports as failed.
- **Profile switch.** A pump basal far from the profile is not used. One notice says the profile
  is set and how the pump rounds it. Pumps report the basal they accepted after a profile set
  (#2454): Carelevo, Diaconn G8, Insight, Equil, Medtrum, Omnipod Eros / Dash, Dana family.
- **Insulin settings.** The edit button is back, so a read-only screen can be unlocked.
- **Quick launch.** The management screens can be put on the toolbar.
- **Scenes.** A scene without a duration draws its temp target and event on the overview again
  and the widget works (#5301). The scenes sheet has an edit button.
- **Sensitivity chip / dialog.** Plain autosens shows the two ISF values too. The effective ISF
  divides the profile ISF by the ratio the loop used.
- **Medtronic.** Sensor records 0x50 / 0x54 / 0x55 have the right length (a 723 is no longer
  shown as suspended by a record dated 2060). A history read that fails on a page is not
  processed, so a temp basal is not ended by the wrong entry. Tests for a bad CRC and a lost
  frame.
- **Dana RS/i.** No reset and no "pump unreachable" alarm when the clock goes forward.
- **Carelevo.** Many fixes: bolus stopped during delivery is recorded from the patch total,
  needle insertion is confirmed again, a discard deletes the stored patch, a write refused
  while BLE is busy is retried for 2 s, and the hand-written `values-ko` is gone (Crowdin).
- **Equil.** The emulator answers a command after an unconfirmed answer, so fill no longer
  times out. Service discovery failure now fails the waiting command at once
  (`linkSetupFailed`) instead of only closing the link.
- **Widget.** The Glance session runs one task at a time and sends every frame, so the widget
  no longer goes empty.
- **Setup wizard.** Every platform opens it on a first run. The permissions step is Android-only.
- **`DateUtil.hourAgo` / `dayAgo`** pass a `Double` to the strings that format `%.1f`.
- **Combo.** A `disconnect()` during the 500 ms connect sleep aborts the next attempt. A Combo
  error lockout gets its own notification id (`COMBO_PUMP_ERROR_LOCKOUT`).
- **Database.** `vacuumDatabase()` returns a `VacuumResult` (`DONE`, `DONE_AFTER_TRIM`,
  `OUT_OF_MEMORY`). When VACUUM runs out of memory it deletes old APS results and device
  statuses and tries once more. This branch keeps the fork rule: **no VACUUM at startup**.
